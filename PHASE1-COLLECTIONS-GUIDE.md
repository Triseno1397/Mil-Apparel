# Phase 1: Create Collections

## Step 1: Import Updated Products (Do This First!)

1. Go to: **Shopify Admin → Products**
2. Click **Import** (top right)
3. Click **Add file** and select: `shopify-products-update.csv`
4. Check the box: **"Overwrite existing products that have the same handle"**
5. Click **Upload and preview**
6. Click **Import products**

This updates all product tags and descriptions automatically.

---

## Step 2: Create Collections

Go to: **Shopify Admin → Products → Collections**

For each collection below, click **"Create collection"** and fill in the fields:
