# Phase 6: Homepage Customization

Go to: **Shopify Admin → Online Store → Customize**

---

## Section 1: Hero (DO NOT CHANGE)

Keep the existing hero section exactly as-is:
- Headline: "Premium Military Apparel for Those Who Serve"
- Button: "Shop all" → /collections/all

---

## Section 2: Branch Collections Grid

Replace the placeholder "Collection title" sections with a collection list or grid.

### In the theme editor:

1. Find the section with placeholder collections (or add a new section)
2. Look for **"Collection list"** or **"Featured collections"** section type
3. Add these 5 collections:

| Collection | Link |
|------------|------|
| Army | /collections/army |
| Navy | /collections/navy |
| Air Force | /collections/air-force |
| Marines | /collections/marines |
| Coast Guard | /collections/coast-guard |

4. **Heading (optional):** `Shop by Branch`

---

## Section 3: Featured Collection - Best Sellers

1. Add a new section: **"Featured collection"** or **"Collection showcase"**
2. **Heading:** `Best Sellers`
3. **Collection:** Select "All products" or create a "Best Sellers" collection
4. **Products to show:** 4-8 products

---

## Section 4: Gifts Section

1. Add another **"Featured collection"** section
2. **Heading:** `Gifts for Service Members`
3. **Collection:** Select "Gifts"
4. **Products to show:** 4 products

---

## Section 5: Trust/Value Section

Add a **"Multicolumn"** or **"Text columns with icons"** section.

### Column 1:

- **Icon:** (optional) shield or star

### Column 2:
- **Heading:** `Operator-Grade Quality`

- **Icon:** (optional) badge or checkmark

### Column 3:
- **Heading:** `Ships Fast`
- **Text:** `Free shipping over $50. Fast fulfillment, every time.`
- **Icon:** (optional) truck or package
